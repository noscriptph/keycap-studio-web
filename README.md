# Keycap Studio (web)

Versión web compilada de **Keycap Studio** (generador y editor de keycaps 3D). El código fuente es privado.

- Todo se ejecuta en el navegador de cada persona; no se suben archivos a ningún servidor.
- Uso gratuito. Prohibida la distribución a terceros, la modificación sin permiso y el uso monetario de los modelos generados. Ver `LICENSE.txt`.
- Las modificaciones y funciones nuevas pueden solicitarse y tienen costo: paillacarelectricidad@gmail.com
